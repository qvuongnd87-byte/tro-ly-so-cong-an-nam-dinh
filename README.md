# Trợ lý số Công an phường Nam Định – V1.0

Đây là bản website tĩnh thử nghiệm phục vụ sáng kiến.

## Mục tiêu V1.0

- Tạo giao diện trung tâm để người dân tiếp cận Trợ lý số.
- Thử nghiệm luồng: Website → câu hỏi → câu trả lời.
- Câu trả lời mẫu hiện được giới hạn theo nội dung phòng ngừa thủ đoạn giả danh Công an để lừa đảo.
- Chưa kết nối AI/API thật.

## Cấu trúc

- `index.html`: giao diện.
- `style.css`: thiết kế.
- `script.js`: chức năng hỏi đáp thử nghiệm.

## Nguyên tắc

AI hỗ trợ – CBCS kiểm duyệt – Người dân sử dụng.

Không đưa dữ liệu nghiệp vụ, danh sách đối tượng, hồ sơ vụ án, mật khẩu, mã OTP hoặc dữ liệu cá nhân nhạy cảm vào bản thử nghiệm.
